# Changelog — YoungPortal

## [1.6.172] — 2026-09-08

### SEO и ссылки
- Канонический сканер `/scanner`; `/scan` даёт 301/308 на `/scanner?tab=pass` (билеты и пропуск — вкладки)
- `/documents` — хаб: политика, правила, соглашение, проверка подлинности + файлы
- В подвале меньше правовых ссылок: документы + 152-ФЗ/cookie
- Общие карточки: `CatalogEntityCard` (проекты/клубы), `HomeLiftFeedCard` (афиша)

## [1.6.171] — 2026-09-08

### Кабинет
- Профиль: bento-сетка — шестерёнка вместо панели кнопок, QR-пропуск 50%, репутация и М-баллы, прогресс+значки+магазин

- Сообщения: optimistic send, свайп вправо к списку на мобильном
- Правка профиля на телефоне — шторка vaul

### Админка
- Command palette Ctrl+K (cmdk): «созд…» → создать новость/проект
- Заявки: slide-over, массовое одобрение, sticky шапка
- Новости: шаги + автосохранение черновика; проекты — расширенный localStorage-черновик
